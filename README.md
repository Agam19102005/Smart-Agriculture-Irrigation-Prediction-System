# Real-Time Smart Agriculture Using Azure Machine Learning and IoT Edge (Hardware-Free)

A software-only AIEC mini project. It simulates IoT sensor readings, trains an ML model, runs local/edge-style inference, and displays live results in Streamlit. An optional Azure ML script registers the model in an Azure ML workspace.

## Features
- Simulated soil moisture, temperature, humidity, and rainfall readings
- Synthetic training dataset generation
- Random Forest irrigation prediction model
- Local inference to demonstrate edge processing without hardware
- Streamlit dashboard with live sensor simulation and history chart
- Optional Azure Machine Learning model registration

## 1. Requirements
- Python 3.10 or 3.11 recommended
- Internet connection for installing packages
- Azure subscription only for the optional Azure ML registration step
- No physical hardware is needed

## 2. Create and activate a virtual environment

### Windows PowerShell
```powershell
cd smart_agriculture_azure_iot_edge
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation, use:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.venv\Scripts\Activate.ps1
```

### Linux/macOS
```bash
cd smart_agriculture_azure_iot_edge
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 3. Train the model
```bash
python train_model.py
```
This creates `data/smart_agriculture_dataset.csv`, `models/irrigation_model.joblib`, and `models/metrics.json`.

## 4. Run the dashboard
```bash
streamlit run app.py
```
Open the local URL Streamlit prints, usually `http://localhost:8501`.

Use **Generate sensor reading** to simulate a new IoT event. Enable **Auto-refresh simulation** for continuously changing readings. The prediction is computed locally, simulating edge inference.

## 5. Optional: register the model in Azure Machine Learning
This step needs an Azure subscription, an Azure ML workspace, and authentication. The core project works without Azure credentials.

1. Create an Azure Machine Learning workspace in the Azure portal.
2. Sign in with Azure CLI:
   ```bash
   az login
   ```
3. Install the Azure ML dependencies:
   ```bash
   pip install -r requirements-azure.txt
   ```
4. Copy `azure_config.example.json` to `azure_config.json` and fill in your subscription ID, resource group, workspace name, and location.
5. Register the trained model:
   ```bash
   python register_azure_model.py
   ```

The script uploads the local model artifact to Azure ML and registers it as `smart-agriculture-irrigation-model`. Keep `azure_config.json` private; it is ignored by Git.

## Model and data notes
The included dataset is synthetic, designed for a classroom demonstration rather than real agronomic decisions. The model predicts a rule-derived label from simulated sensor values. Do not use the output to control real irrigation equipment.
